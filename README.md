# Avatars
\n## Naming Convention
\nFor each avatar, create a folder named after the avatar (e.g., `my-avatar-name`). Inside this folder, the following file naming scheme is expected:
\n- **Avatar Folder:** `avatar-name/`\n- **Bust Thumbnail:** `avatar-name/thumb-bust_avatar-name.png`\n- **GLB Preview Thumbnail:** `avatar-name/thumb-glb_avatar-name.png`\n- **GLB Model:** `avatar-name/avatar-name.glb`\n- **VRM Model (Optional):** `avatar-name/avatar-name.vrm`\n- **Markdown Bio:** `avatar-name/avatar-name.md`
